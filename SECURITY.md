# Security policy

## Supported versions

There is no supported public release while this repository remains in staging. Supported versions will be listed here when the first certified release is published.

## Reporting a vulnerability

Use the repository's private vulnerability-reporting feature under **Security → Advisories → Report a vulnerability**. Do not open a public issue for a suspected vulnerability and do not include secrets, personal data, private service details, or exploit data in benchmark fixtures.

Include the affected version or commit, the smallest reproduction you can provide safely, the expected impact, and any relevant environment details. Repository maintainers will coordinate disclosure through the advisory.

## Scope notes

Benchmark agreement is not a security guarantee. Reports about numerical accuracy or external-reference drift belong in normal issues unless they also create a security impact. Swiss Ephemeris licensing questions are legal or supply-chain matters, not security vulnerabilities.
